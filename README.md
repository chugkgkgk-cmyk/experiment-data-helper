# 실험 데이터 처리 도우미

전곽 SW 경시대회 2026 출품작 · 분야: 교육활동 개선 · 개발 형태: 웹

실험 보고서를 쓸 때 측정값을 붙여 넣으면 평균과 불확도, 그래프의 기울기, 유효숫자에 맞춘 계산 결과를 보고서에 바로 쓸 수 있는 형태로 정리해 주는 웹 도구입니다. 결과마다 계산 과정을 펼쳐 볼 수 있습니다.

## 실행 방법

- **웹에서 바로 쓰기:** https://chugkgkgk-cmyk.github.io/experiment-data-helper/
- **시연 영상(2분 9초):** https://chugkgkgk-cmyk.github.io/experiment-data-helper/demo.mp4
- **내 컴퓨터에서 쓰기:** 저장소의 `index.html`을 내려받아 크롬이나 엣지로 열면 바로 실행됩니다. 설치할 것이 없고 인터넷 연결도 필요 없습니다.

입력한 값은 브라우저 안에서만 계산되고 어디에도 저장하거나 보내지 않습니다.

## 기능

1. **반복 측정** — 같은 양을 여러 번 잰 값을 넣으면 평균, 표준편차, 평균의 표준오차를 구하고 `T = 1.425 ± 0.008 s`처럼 정리합니다. 불확도 기준(표준오차, 표준편차, 기기 불확도, 둘의 합성)과 불확도의 유효숫자(1자리, 2자리)를 고를 수 있습니다.
2. **그래프·기울기** — 두 물리량을 한 줄에 하나씩 넣으면 그래프를 그리고 최소제곱법으로 기울기와 절편, 그 불확도, 결정계수를 구합니다. 제곱·제곱근·역수·자연로그 변환으로 곡선 관계를 직선으로 바꿔 볼 수 있고, 원점을 지나는 직선도 고를 수 있습니다.
3. **유효숫자 계산** — `(51.05 - 48.126) / 58.44 / 0.2500` 같은 식을 넣으면 단계마다 어떤 규칙이 적용됐는지 보여 주며 최종 답을 유효숫자에 맞춥니다. 숫자 하나만 넣으면 유효숫자 개수를 알려 줍니다.

## 계산 방법

| 항목 | 식 |
| --- | --- |
| 표준편차 | s = √( Σ(xᵢ − x̄)² ÷ (n − 1) ) |
| 평균의 표준오차 | s ÷ √n |
| 합성 불확도 | √( 표준오차² + 기기 불확도² ) |
| 불확도 반올림 | 유효숫자 1자리(또는 2자리)로 반올림하고, 평균은 불확도의 마지막 자리까지 반올림 |
| 기울기·절편 (y = ax + b) | a = Sxy ÷ Sxx, b = ȳ − a·x̄ |
| 기울기·절편의 불확도 | s = √(잔차 제곱합 ÷ (n − 2)), s_a = s ÷ √Sxx, s_b = s × √(Σx² ÷ (n·Sxx)) |
| 원점을 지나는 직선 (y = ax) | a = Σxy ÷ Σx², s = √(잔차 제곱합 ÷ (n − 1)), s_a = s ÷ √Σx² |
| 유효숫자: 덧셈·뺄셈 | 끝자리가 가장 높은(덜 정밀한) 수의 자리에 맞춤 |
| 유효숫자: 곱셈·나눗셈·거듭제곱 | 유효숫자 개수가 가장 적은 수에 맞춤 |

- 끝이 0인 정수(예: `1200`)는 유효숫자가 애매해서 0을 빼고 셉니다. 0까지 유효하면 `1200.`이나 `1.200e3`으로 씁니다.
- 개수나 정의값처럼 정확한 수는 `{4}`처럼 중괄호로 감싸면 유효숫자 계산에서 제외합니다. `pi`도 정확한 수로 봅니다.
- 중간 단계에서는 반올림하지 않고, 몇 자리까지 의미가 있는지만 따라가다가 마지막에 반올림합니다.

## 계산 검증

`tools/verify.py`는 앱의 계산 함수를 numpy·scipy 결과와 비교합니다. 평균·표준편차·표준오차, 최소제곱 기울기·절편과 그 표준오차, 결정계수, 반올림, 유효숫자 세기와 식 계산을 확인합니다.

```
pip install numpy scipy playwright
playwright install chromium
python tools/verify.py
```
